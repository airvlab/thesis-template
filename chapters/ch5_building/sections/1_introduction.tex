\section{Introduction}\label{ch5sec:build-intro}

A well-written thesis is useful only if it can be compiled reliably and shared with readers. This chapter explains the build system, common errors, arXiv submission, and preview generation. By the end of the chapter you should be able to produce a clean PDF and understand how to submit it to common repositories.
