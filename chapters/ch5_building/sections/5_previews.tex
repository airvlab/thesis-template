\section{Previews}\label{ch5sec:previews}

While writing, it is helpful to preview the output without rebuilding the entire thesis every time. The template's \texttt{Makefile} includes a \texttt{preview} target that rebuilds \texttt{build/main.pdf} and extracts showcase PNGs into \texttt{docs/images/preview/}. These PNGs are embedded in \texttt{README.md} so the repository always shows the current template output. You can extend the target for your own workflow.

\subsection{Fast Feedback}

For rapid iteration, many editors can run \texttt{latexmk} in continuous mode with \texttt{-pvc}. This watches source files and rebuilds the PDF automatically. Because the template redirects output to \texttt{build/}, point your viewer at \texttt{build/main.pdf}.

\subsection{Checking the Output}

Before submission, inspect the list of figures, list of tables, and table of contents for missing or broken entries. Warnings about undefined references or citations should be resolved unless they are intentional placeholders.
